# 沖印裁切工作台 · 20.5 × 9.5 cm

前端相片沖印工具。上傳照片後自由移動、縮放、旋轉，按下「確定裁圖」即可下載**嚴格符合 20.5 × 9.5 公分、300 DPI** 的無損 PNG。另附 Agnes AI 的兩項功能：對上傳照片調整**姿勢與畫風**（圖生圖），以及從**文字生成圖片**。

🔗 **線上使用**：https://ericliao2015.github.io/mug/

---

## 輸出規格

| 項目 | 值 |
|---|---|
| 成品尺寸 | 20.5 cm（寬）× 9.5 cm（高） |
| 解析度 | 300 DPI |
| 像素 | **2421 × 1122 px**（`20.5 ÷ 2.54 × 300`、`9.5 ÷ 2.54 × 300`） |
| 格式 | PNG（無損，不做任何有損壓縮） |
| 物理尺寸標記 | 寫入 PNG `pHYs` chunk = 11811 px/m，列印軟體會自動判讀為 20.5 × 9.5 cm |

裁切框比例永遠鎖定 20.5 : 9.5，**不會拉伸變形**。每次下載後程式會把產生的檔案讀回來實測像素，確認是 2421 × 1122 才顯示綠色驗證訊息。

## 功能

### 裁圖台
- 拖曳移動、滾輪／雙指縮放（以游標或雙指中點為錨點）、方向鍵微調（Shift 加速）
- 左右轉 90°、填滿裁切框、完整顯示、置中、重設
- 三分構圖線與安全邊界參考線
- **即時取樣解析度顯示**：放太大導致低於 300 DPI 時會警告
- **留白偵測**：框內有空白時醒目提醒，下載時空白處填白色

### AI 改圖（裁圖台內，可選）

把上傳的照片送給 Agnes AI 做圖生圖，調整人物**姿勢**或**畫風**：

- **姿勢** 6 種：維持原姿勢、自然站姿微笑、手比愛心、跳躍動感、比讚手勢、勾肩搭背
- **畫風** 6 種：吉卜力、迪士尼皮克斯、韓劇質感、80 年代復古、樂高公仔、蒸氣波
- 兩組可單獨或合併使用
- 改圖一律從**原始照片**出發（不是從上一次的結果），避免反覆重繪劣化
- 隨時可按「還原成原始照片」退回
- 結果直接回到裁切舞台，可繼續移動縮放後輸出

提示詞依模式分成兩套：

| 模式 | 行為 |
|---|---|
| 只改姿勢 | 鎖住畫風、服裝與原始背景，只動姿勢 |
| 有選畫風 | 全圖含背景一起套用該畫風，僅保留人物身分與服裝 |

分兩套是因為「保留原背景」會跟畫風指令打架 —— 人物轉成卡通、背景卻留實拍，同一張圖出現兩種畫風。

**80 年代復古**是唯一會換掉服裝的畫風（高腰褲、寬尖領、針織背心、墊肩西裝、燙捲髮、側分），並額外提供一支**「老舊程度」滑桿**：褪色、降對比、黑位上浮、底片顆粒與四角暗角都在**瀏覽器本機**疊加，調整即時生效、不重新呼叫 API、不花額度。

> 為什麼老化不交給 AI？實測過。圖生圖模型對輸入照片的保真度很高，會抵抗「把照片弄舊」這類大幅劣化，提示詞再怎麼加字效果都有限。所以換裝與髮型交給 AI（只有 AI 做得到），相紙劣化在本機做（確定生效、可調、免費）。

> ⚠️ 使用這項功能時，照片會上傳到 Agnes AI 伺服器。介面上有**強制勾選的同意欄**，未勾選無法送出。若處理的是他人肖像（學生、活動照片），請先取得當事人同意。

### AI 生圖
- 中文提示詞（自動併入英文構圖／品質指令）
- 12 種風格預設（水彩、吉卜力、3D 動畫、水墨、膠卷、霓虹、剪紙…）
- **生成高度 4 選項**：滿版 9.5 cm / 8.5 cm / 7.5 cm / 6.5 cm
  - 選擇較矮的高度時，圖片等比縮放後**垂直置中**，上下自動補白，畫布仍固定 2421 × 1122
- 生成結果可直接下載，或「送進裁圖台」再手動微調構圖

裁切、縮放與輸出都在瀏覽器本機完成。**只有在你主動使用「AI 改圖」時，照片才會送出**；「AI 生圖」則只送出提示詞文字。

## ⚠️ 關於 API 金鑰的安全性

**請先讀這段再決定要不要用內建金鑰。**

內建的 Agnes AI 金鑰採用：

- **AES-256-GCM** 加密
- **PBKDF2-SHA256，210,000 次迭代**推導金鑰
- 通關密語由三段散落在原始碼不同位置的常數 + **當前網域名稱**組成
- 每個授權網域各自一組獨立的 salt / IV / 密文

因此：

- ✅ 原始碼中**不存在明文金鑰**，GitHub 的 secret scanning、爬蟲、搜尋引擎都掃不到
- ✅ 把 `index.html` 複製到未授權的網域（例如別人鏡像一份）**無法解出金鑰** —— 該網域在 vault 裡根本沒有對應項目
- ❌ **但這是純靜態網站，沒有後端。** 頁面執行時金鑰必然會還原成明文才能送出請求，任何人打開 DevTools 的 Network 分頁就能看到 `Authorization` 標頭

**結論：加密能擋住原始碼掃描與隨手複製，擋不住刻意攔截的人。** 請把內建金鑰視為「展示用、可拋棄」的額度，並定期到 [platform.agnes-ai.com](https://platform.agnes-ai.com/settings/apiKeys) 更換。

使用者也可以在頁面上切換成「使用我自己的金鑰」，該金鑰只會存在自己裝置的 `localStorage`。

### 更換內建金鑰

```bash
node tools/reseal-key.mjs sk-你的新金鑰
```

腳本會重新加密並直接改寫 `index.html` 的 VAULT 區塊，明文不會寫進任何檔案。要改授權網域的話，編輯 `tools/reseal-key.mjs` 裡的 `HOSTS` 後重跑。

### 想要真正安全？

把金鑰移到 Cloudflare Worker（或任何 serverless 函式）的環境變數，前端改呼叫自己的 Worker 網址。頁面仍可放在 GitHub Pages。這是唯一能讓金鑰不外流的做法。

## 本機開發

```bash
python -m http.server 8765
```

然後開啟 http://localhost:8765 —— `localhost` 已在授權網域清單內，內建金鑰可正常解密。

---

## 部署

推送到 `main` 後，到 GitHub repo 的 **Settings → Pages → Build and deployment**，Source 選 **Deploy from a branch**，分支選 `main` / 根目錄 `/`，儲存後約 1 分鐘即可上線。

## 瀏覽器需求

Chrome / Edge / Firefox / Safari 近兩年版本。需要 `Web Crypto`（HTTPS 或 localhost）、`Pointer Events`、`canvas.toBlob`。
